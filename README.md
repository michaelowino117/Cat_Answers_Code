# Cat_Answers_Code
Artificial Intelligence Agents & Search Algorithms
 Overview

This project contains Python implementations of core Artificial Intelligence concepts:

A* Search Algorithm (Informed Search)
Vacuum Cleaner Agent (Simple Reflex Agent)
 A* Search Algorithm

The A* algorithm is an informed search technique used to find the optimal path using:

f(n)=g(n)+h(n)
 Output

Displays the optimal path from the start node to the goal node.

 Vacuum Cleaner Agent

A simple AI agent that cleans two locations (A and B) by:

Detecting dirt
Cleaning the location
Moving between locations until all are clean
 Output
Shows cleaning actions and movement until all locations are clean.

 Key AI Concepts Used
Informed Search (A*)
Heuristic Functions
Reflex Agents
Environment–Agent Interaction
 Requirements
Python 3.x
No external libraries required
